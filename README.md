# dsh-autostart —— dsh web 开机自启 + 隐藏窗口 + 崩溃自动重启

> 🌐 **English**: see **[README.en.md](README.en.md)**

一个 Windows 小工具包，让 **DeepSeek Harness 的网页端（`dsh web`，默认
`http://127.0.0.1:3080`）** 做到：

- 🚀 **开机自启**：登录后自动以隐藏窗口启动，不弹命令行黑窗；
- ♻️ **崩溃自动重启**：`dsh web` 意外退出后约 2 秒自动拉起；
- 🪄 **一键接管**：如果你已经用别的方式跑着 `dsh web`，运行本工具会直接
  **接管**它、由它负责守护，崩溃即自动重启；
- 🧩 **改页面不用重启**：配套的 `dsh-chat` 插件把 `public/*` 静态页改成
  **每次请求实时读盘**，改完刷新浏览器即见，无感、不打乱进行中的对话。

> 纯 PowerShell / VBS / cmd 编写，**无需编译、无需 dsh 插件体系**。双击即可用。

---

## ✨ 怎么用（别人也能这样用）

> 前提：本机已装 Node.js，且能跑 `dsh web`（DeepSeek Harness）。

**一键配置（推荐）**

1. 下载/克隆本仓库到任意目录；
2. **双击 `setup.cmd`** —— 它会自动：
   - 把 `start-dsh-web.vbs` 装进「启动」文件夹（以后开机自启）；
   - 在后台启动守护进程（隐藏窗口）；
   - 若已在跑则**接管**现有 `dsh web`；
   - 检查 `http://127.0.0.1:3080` 是否可访问。

之后 dsh web 就处于守护状态：开机自启、崩溃自动重启。

**常用命令**（在本目录的 `cmd` 里执行）

```
setup.cmd            一键配置并启动守护
setup.cmd -stop      停止 dsh web 并禁用自动重启
setup.cmd -start     恢复守护（清除停止标记）
setup.cmd -uninstall 移除开机自启（不停掉正在运行的 dsh web）
```

## 📦 文件说明

| 文件 | 作用 |
| --- | --- |
| `setup.cmd` | **一键入口**，双击即用（中文界面） |
| `start-dsh-web.vbs` | 开机隐形启动入口（登录时以隐藏窗口拉起守护） |
| `dsh-web-launcher.ps1` | 守护进程本体：隐藏启动、接管现有实例、崩溃自动重启、哨兵控制 |
| `install.cmd` | 细粒度安装/卸载（`-start` / `-stop` / `-uninstall`） |
| `readme.txt` / `说明.txt` | 中文使用说明 |
| `logs/` `run/` | 运行时目录（自动生成，不入库） |

## ⚙️ 自定义

打开 `dsh-web-launcher.ps1` 顶部参数：

- `-Port`：端口，默认 `3080`；
- `-RestartDelay`：崩溃重启间隔（秒），默认 `2`。

改完即生效，无需重新安装。

---

## 🔒 说明 / 限制

- 本工具只做**进程级守护**，不是 dsh 插件；它包在 `dsh web` 外面。
- 若本机已用别的方式/端口在跑 `dsh web`，先统一端口再启用，避免双实例抢占。
- 如果本来就有其他自启/任务计划在管 dsh web，别重复启用本工具。

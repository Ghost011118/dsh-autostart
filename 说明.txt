============================================================
 dsh web 开机自启 + 隐藏窗口 + 崩溃自动重启 —— 一键配置
============================================================

【怎么用（本机双击即可）】
  1. 把整个 autostart 文件夹放到你 Windows 电脑任意位置；
  2. 双击  setup.cmd：
       - 自动把 start-dsh-web.vbs 装进「启动」文件夹（开机自启）
       - 立刻在后台启动守护进程（隐藏窗口）
       - 如果 dsh web 已经在跑，守护进程会「接管」它；之后它崩了
         会自动在两秒左右重启
       - 检查 http://127.0.0.1:3080 是否可用
  3. 结束。以后开机 dsh web 自动以隐藏窗口启动；崩溃自动重启。

【常用命令（在 autostart 文件夹的 cmd 里执行）】
  setup.cmd           一键配置并启动守护
  setup.cmd -stop     停止 dsh web 并禁用自动重启
  setup.cmd -start    恢复守护（清除停止标记）
  setup.cmd -uninstall 移除开机自启（不会停掉正在运行的 dsh web）

【文件说明】
  setup.cmd              一键入口（双击这个）
  start-dsh-web.vbs      开机隐形启动入口
  dsh-web-launcher.ps1   守护进程本体（隐藏启动 + 崩溃自动重启）
  readme.txt             详细说明（含“改页面为何要重启”的三层原理）
  logs\                  守护进程日志（launcher-*.log）

【调快/调参】
  改 dsh-web-launcher.ps1 顶部的 -RestartDelay（当前默认 2 秒，越快恢复
  越快）；端口默认 3080（-Port）。改完 ps1 即生效，不必重装。

【提醒】
  * 若你本来就用别的办法/别的端口在跑 dsh web，先确认端口一致，否则会
    有两个实例抢端口。
  * setup.cmd 是纯英文输出，是为了任何中文/编码环境下都不乱码；配套的
    中文说明请看本文件。
